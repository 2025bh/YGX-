# 家具短视频制作：项目方案与完整接收规则

版本1.0.0，2026-10-10。可直接交给同事的Agent读取；不要求访问发起人的电脑或聊天历史。

## 我们在做什么

我们为实体家具业务建立可重复的视频制作流程。多个项目、账号和平台各有不同定位：实木全屋定制品牌内容、家具工厂员工带看、板式定制门店案例、仓库清货。主要视频有两种：好素材配原创旁白的家具混剪，以及真人出镜串联空间和细节的案例种草。

每个账号找自己的对标，学习结构、画面和表达，再用自己的真实素材持续制作。核心目标是流程能跑通、画面与文案准确、剪映可继续编辑，不以估算节省时间或某次播放量替代落地验收。当前不做直播，不默认自动发布，不跨项目套品牌事实。

## 接收方拿到什么、还缺什么

拿到：`produce-furniture-video` Skill、完整制作规则、剪映移机验收流程、配置模板、镜头计划模板、计划校验脚本。本文件把业务目标、执行办法和规则直接写清楚，单独接收也能理解。

不包含：任何原始视频、参考视频、客户数据、剪映账户/订阅、克隆音色模型、音乐版权或发起人的营销视频后端。安装Skill仅安装方法与检查工具，不等于安装了自动剪辑软件。只有本文时Agent也可制定计划；要真做视频还须接收方的素材和可用工具。

接单先问缺失项：项目/账号/平台/人设、授权素材与参考位置、完整来稿或允许原创、时长与输出目录、配音方式、音乐授权、是否需剪映导入。收到过的输入不重复询问。先预检Python、FFmpeg/ffprobe、剪映和原生操作工具；没有不假装有，不自行付费或上传素材。

## 完整执行方案

1. 明确归属与输入，核对已有结果及唯一执行权。账号不明确标“未指定，仅本地审片”，不虚构身份。
2. 参考分析先元数据和少量联系表，再看候选区间；拆内容结构、镜头时长、构图/运动、字幕、文案、配音音乐。场景切点仅候选，不把运镜/字幕动效误判当真实切镜。
3. 索引授权自有素材，记录原片身份、哈希、路径、时长、分辨率/比例/帧率、有效采用区间。文件变更重新索引；路径含“暂时不可用”一律排除。
4. 先实际看可用画面，再写原创稿；有完整来稿则按原稿制作审片版，未证实项单列。不靠文件名选片。逐句列主体、动作、需证明的细节，选镜头并保留理由和缺镜头项。
5. 先完成最终旁白，再排镜头/字幕。当前配音路线是“真人播客女”文本朗读生成干净音频，再对该音频换为“春燕”克隆音色；先小样试听。同事账号没有该音色时索取最终音频或请用户确认替代配置。
6. 逐镜头预审采用区间与前后切点，形成统一时间线，画面/每条文字/旁白/音乐/音效分别可编辑；普通镜头时长门禁不可突破。
7. 输出审片MP4和独立文本剪映草稿，收齐所有依赖制作工程包，核验真实元数据、帧数、全片解码、区间、去重、音轨、字幕、路径和哈希。计划JSON校验不能替代真实文件检查。
8. 实际导入并原生验证首页可见、素材在线、播放、编辑隔离、保存重开和导出。缺原生工具则清楚标待验，交付具体动作；不是说“ZIP已有所以草稿导入成功”。
9. 让用户审片，纠正写到对应层级；用户认可才升为账号正式风格，实际发布证据才标发布，未经授权不自动发布。

## 必须遵守的制作规则

### 选片、节奏与比例

- 当前仅9:16源视频、9:16输出；不裁横版、不拉伸。老横版任务不是现行默认。
- 同一条默认同一原片只用一次，不同区间/改名/复制/派生片也算；另做近似画面视觉去重。跨视频可复用自有素材；特殊重复先经本条明确同意。
- 选稳定、不明显抖动、速度与相邻镜头大致一致、清晰、不明显倾斜、主体适合当前镜头完整展示的素材。优先换片，不强防抖/裁切/加减速掩盖质量。
- 原片足够长时避首尾各1秒；已人工裁切精选须查原片区间和证据，不机械二次裁。短原片换素材或记录获准例外，但普通镜头仍不得短于1.5秒。
- 普通镜头全部1.5至4秒，一般约2至3秒，按句意、动作完成度定，不机械等长。
- 仅文案连续列举不同产品如“沙发、茶几、衣柜”可用短于1.5秒快切，每镜对应产品、选择最稳定区间、标记理由；不能因强调就快切。
- “柜门、柜体、内部隔层”同产品部件不三段快切，用带柜门和无柜门内部框架两个镜头；其他部件按实际结构安排。
- 整句统筹：覆盖6秒不做5+1秒，改3+3等合法组合。短尾重新分配，不重复、冻结、变速凑长度。

### 文案与事实

- 产品指示句对所指真实产品；纹理配近景、拼接配部件/动作、空间配整体。柜体不能冒充床。
- 地点、原料、生产、参观、价格说明、咨询可用同项目相关空镜，不要求每句产品特写；参观者不等于成交客户。
- 没床只暂停床那句，不等于所有素材不可用；不相关家具不冒充，缺镜头给补拍需求或经许可改稿。
- 不编造材质、榫卯强度、环保、年限、价格比例、最高级、客户评价和成交。单帧成品不能证明这些；来稿未证实宣传单列，未经允许不改稿、不发布。
- 对标只学结构节奏不搬品牌地址价格身份或音乐，语音识别错误对照原音校正。没有生产素材就用展厅主线。
- 工厂路线：具体问题/地点→原料/分区→工序与真实人物→成品→咨询，远中近景递进。30至40秒是类型参考；用户时长优先，每个镜头仍受限。
- 展厅路线：选购问题→空间→部件→组合搭配→需求→留言；真人案例真实讲述串空间与细节，不语义误剪。不开新永久窗口处理普通子步骤。
- 旧样片约33/40秒且用户反馈5000+浏览，只证明历史形式有观察价值，不能推出剪法保证效果。旧1秒镜头统计不覆盖当前时长规则。

### 配音、音乐与独立文字

- 真人原片保留真实原音；合成旁白标记。当前合成路线：文本朗读“真人播客女”→生成音频→选音频换音色“春燕”，不使用瑶瑶、不改成春燕重新朗读、不双人声叠加。
- 保留原始朗读及换音色版本，只转换干净旁白，不把音乐音效送入换音色。先试听激情、重音、停顿、节奏、音色、咬字、漏错字、破音和时长，不承诺情绪100%保留。
- 春燕是账号已有授权克隆音色，不包含在Skill内；没权限或入口不可用则停止该环节，不擅自换音色或训练。账号登录、购买、付费确认由用户处理/授权。
- 最终旁白定稿后对齐镜头字幕；更换配音后时长变了重新排镜，不能只塞回旧时间线。
- 必须有音乐、少量强调音效、同步字幕；人声优先，音乐低于人声且首尾淡化，不每个切点加音效。无许可音乐不能称可商用；原片噪声非叙事需要时静音。
- 文字每条独立素材和片段，可复制初始样式不共享可变引用；普通文本优先，关闭字幕/歌词同步，不文字分组关联。改一条其他不能变；配音生成不能破坏独立字幕。
- 重点词黄色填充、黑描边、阴影，普通白字，一句通常一个重点；不遮产品或平台控件，安全区须原生实看。只有实际选用才说是剪映内置预设，程序等效样式叫自定义。

### 工程、导入与验收

- 素材、声音、文字分轨，工程包收齐视频、音频、图片等依赖，SHA256清单及移机重定位；不要求同事有作者本地路径。
- 剪映草稿位置/首页索引从接收方实际配置和可见工程核对，两者可能不同盘。兼容导出器不存在时走剪映原生UI，不猜导入协议、不只写一个JSON冒充可用工程。
- 外部索引登记前准备齐完整包/目标/索引/ID/检查方法，用户保存并完全退出、确认进程退出后，先备份再只增补目标条目；保留旧条目和ID。不强关、不运行中外部改索引、不整份旧备份覆盖当前索引。
- 重复导入回读原结果，不覆盖精修；回读素材与索引后才请重开。原生截图/用户确认才称首页可见；保存重开和导出单独验收。
- 联系表仅初筛；采用区间与切点前后连续检查。无播放工具至少每段10帧、间隔≤200ms加前后切点，标“时序预审”，不能标连续播放已验收。
- 完整解码、比例/帧数/区间/去重/路径/哈希/文字独立检查后，原生再做播放、修改、保存重开和导出。工作副本隔离测试，不改精修原稿。FFmpeg截图/静态结构不能替原生安全区检查。
- 分开报告文件生成、包完整、索引登记、首页可见、编辑保存重开、用户认可、已发布。超时先查实际结果只补缺步；看不到时查目录索引进程，不反复无依据重开，不删除失败产物。
- 本地规则有后续纠正则按作用域升级版本；当前任务规则冻结。未安装工具不说已运行，没有定时进程不说持续监控。
