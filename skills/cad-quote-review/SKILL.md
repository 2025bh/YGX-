# CAD报价识别与纠错

先确认本次是识图、复核、规则整理还是平台制作；沿用用户已确认的范围与项目版本，不把参考截图或历史答案直接当成本次测量。

## 入口与资料

- 识别、算量或纠错时读取[报价规则](references/quotation-rules.md)，按本项目适用条件执行；C/B端、项目售价和共用工程量分别管理。
- 制作平台时读取[平台执行要求](references/platform-workflow.md)。已有平台优先接入其数据库和接口；技能本身不包含CAD程序、识别模型或生产系统。
- 使用[数据与证据约定](references/data-contract.md)组织输出，使用[匿名示例](assets/demo-quote.json)验证格式，不把演示数据当作客户结果。
- 公开分享时读取[脱敏与发布](references/publication.md)，用显式文件清单发布；原DWG、DXF、报价表、截图、客户信息和凭据保留在用户指定的私有目录。

## 识图与独立复核

绑定项目、客户类型、图纸版本哈希、绿色图号、图框范围及对象句柄。先看DWG原图及全部相关副图，再用同版DXF查对象和量测数值。优先原生标注，缺总尺寸时复核完整实体边界与尺寸链；记录采用值、来源、冲突和未测项。

每张图检查正视、俯视、侧视、节点、图签名称和完整材料说明。材料文字只能提示检查对象；见光板是否存在及其尺寸必须回到几何核实。按整件与可独立计价部件分项，不默认将C端整柜拆成所有柜体、柜门和内部板件。

AI原稿先独立生成并冻结，再接入用户指定的人工对照。历史纠错案例可指导看图和分项；案例尺寸不能复制为新图实测值。已经看过的项目称回归复核，未见图才可作盲测。

## 算量与审核

计价单位决定工程量。面积、总长和数量分别计算，面积不能乘总长。必要输入缺失或单位待确认时保留原因，不编数、不把空值改成零或默认数量。书桌、脚线和已确认的低矮电视柜按延米；低矮电视柜保留高风险。

高风险不妨碍计算有证据的工程量。底层保留原始精度，展示两位；金额使用未取整工程量乘经确认单价。没有项目单价时金额留空。调用脚本时明确选择矩形、延米、数量或人工展开口径；B端未经确认不套C端收费方法。

```text
python <技能目录>/scripts/calculate_quote.py <本项目JSON> <独立输出JSON>
python <技能目录>/scripts/test_calculate_quote.py
```

## 纠错与复用

每项保存修改前后、项目/版本/图号/部件、截图及标记、错误理由、图纸读法、计算方法、操作者和时间。漏项补入、误计项标记不计价、错误匹配人工重新配对；未测完暂存待测量。

项目数值属于本项目；复用规则保存适用范围、条件、排除条件和证据。规则文字保存不等于程序学会：未有执行适配和回归证据时标待适配，不自动覆盖现行规则或历史报价。支持相同请求重试与版本冲突检查，避免重复计价和静默覆盖。

## 交付与边界

交付逐图部件清单、单位与完整适用尺寸、原值工程量、材料、依据和风险；按用户模板输出审核稿，保留其列、样式和已确认公式。CAD原图参考图不得用DXF重绘冒充。

区分文件生成、计算验证、CAD原生核验和老师傅业务验收。平台第一版可以导入既有识别结果；未连接的CAD、未实现的一键识别、门线/五金/项目价格必须如实说明。未经当前任务授权不改正式报价、不上传私有业务文件、不删除历史产物。
