# 逐题审核规则

整份AI报价与用户指定的人工报价完整对比，先差异题卡，再逐图查漏。一个部件的尺寸、单位、工艺和衍生工程量差异合成一题，不把面积和金额变化拆成重复劳动。

先按项目、同版图纸、区域和可靠位置建立部件对应关系。只有唯一匹配自动配对，同名多件、异名同物、整件与拆分行先核实匹配；人工确认的别名默认只适用于本项目。

人工原表缺图号时保留待配图，序号不是CAD绿色图号。规格单位mm不能作为收费单位；仅在人工明确确认后，由单一面积列或总长列判断计价口径，两列都有值保持待核。配对确认仅更新工作对应关系，保留冻结原稿与解析来源。

卡片列AI值、人工报价值和本次确认值，提供采用任一方、第三种答案和待查。人工报价不是绝对真值，不能无确认覆盖原稿。采用来源数据时不继承旧采用稿缺失的单价或最低面积；预览与保存使用同样候选字段和计算方法。

老师傅可以只指出问题、不先算答案。原话、图上位置、截图与标记和改前改后由系统留存；整理的读图方法不能编造未观察的尺寸链。确认当前项目与推广通用规则分开，C/B范围自动带入项目但推广仍需确认条件。

图纸定位必须同源哈希。无可靠对象绑定只称图框定位；截图、任务及修改绑定行版本，换版或并发冲突不静默覆盖。刷新前保护未保存草稿。

逐图查漏使用独立于报价行的图框清单，零报价项图必须进入队列；缺清单时只能说明已列报价图号核对完成。每图独立校验待配对、缺工程量和未确认收费口径，不能因候选卡隐藏而放行。

确定公式先核原始输入再算结果，延米无计价面积，缺价金额空，底层原值计算，显示取整差异注明。重复请求幂等；撤销保留历史并撤回本次生成的规则候选；换版后相关题目重新核对。

验收覆盖配对歧义、多差异单卡、待查续做、第三答案、缺尺寸、B端门禁、截图绑定、源版本冲突、重复提交、撤销、零报价图框、桌面和手机。真实师傅PC及使用耗时未经实测不称业务验收通过。
