# 家具素材审核剪辑

把手机直出素材整理为可复用精选片段，并按文案生成可审核的家具短视频粗剪。

## 适用范围

- 家具展厅、门店、工厂和装修案例短视频
- 本地素材扫描、技术检查、自动切片和人工片段审核
- 文案节拍拆分、已验证素材匹配、低清粗剪
- 剪映真人播客女朗读稿和简单字幕 demo

## 最小输入

只提供手机原片时，可以完成素材扫描、自动切片和素材净化。要继续精准匹配并生成成片，还需要完整文案、项目名称，以及安装了 FFmpeg/ffprobe 的本地环境。

## 使用

安装时保留整个 skills/furniture-review-cut 目录。先读取 SKILL.md，需要项目背景时再读取 references/project-overview.md。

技能不会上传素材、删除原片或自动发布平台。剪映音色替换由用户在剪映草稿中完成。
