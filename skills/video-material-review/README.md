# 视频素材筛选与分类

[返回仓库首页](../../README.md) · [查看完整执行规则](SKILL.md)

## 用来做什么

从家具、空间、工艺和生活场景原视频里找出值得保留的镜头区间，按项目、主体和用途建立索引，并记录人工反馈。适合多项目、多账号共用一套素材库的工作方式。

实际判断要看画面内容和时间变化。文件名、分辨率、技术指标和自动检测结果只能帮助定位候选，不能代替视觉审核。

## 典型工作流程

1. 确认素材目录、项目归属、账号用途、来源及可用工具。
2. 只读扫描原片，提取候选区间与必要画面证据；有实际可用的视觉模型时，再结合画面审核主体、构图、清晰度和氛围。
3. 分别记录每个可用区间的时间、分类、评分依据、置信度与待复核项；一个原片可以有多个区间。
4. 在已有素材台或索引中保存“喜欢”“不喜欢及原因”“不采用”和分类修订，后续据此调整筛选偏好。

**筛选规则提醒：** 成品参考视频只用于学习，不进入可用素材；发现文字或水印的原片不采用。网络下载素材还要满足竖屏、无人物等要求。具体边界以 [SKILL.md](SKILL.md) 为准。

## 交付与使用条件

交付的是可追溯的镜头索引、候选区间和审核记录。原始视频不因筛选而移动、覆盖或删除；没有真实画面证据时，相关判断保持待确认。

本 Skill 是规则文件，不附带素材台软件、FFmpeg 或视觉模型。若要读取本地素材，接收方需提供自己的路径和工具；若要把原视频或截图上传到外部服务，先确认上传范围。
