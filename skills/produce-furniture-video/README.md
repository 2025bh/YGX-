# 家具短视频制作

[返回仓库首页](../../README.md) · [查看完整执行规则](SKILL.md)

## 用来做什么

用已确认的家具实拍素材制作品牌号、工厂员工号、门店案例或清货账号短视频。覆盖参考分析、文案与画面匹配、镜头节奏、配音、字幕和可编辑剪映交付。

有大量未整理原片时，可以先使用[视频素材筛选与分类](../video-material-review/README.md)建立候选镜头库，再进入制作。

## 典型工作流程

1. 确认项目、账号、视频任务、参考内容、可用素材和输出位置。
2. 查看候选镜头的真实画面，为文案逐句匹配主体、动作和需要证明的细节。
3. 按完整规则安排镜头、配音、音乐与字幕；保持文字逐条独立可编辑。
4. 审看导出视频，并在剪映中检查草稿能否打开、编辑、保存、重开。

当前规则包括 9:16 源与输出、普通镜头 1.5 至 4 秒、同一原片不重复，以及只有连续列举不同产品时才使用短快切。完整例外和验收方法见 [SKILL.md](SKILL.md)。

## 交付与使用条件

按任务交付当前版本的视频、文案、镜头清单和可编辑剪映工程。是否已生成文件、能否在剪映原生编辑、是否通过审片，应分别核验。

本 Skill 包含规则、模板及计划校验工具，不包含原始视频、剪映程序或账号、克隆音色模型、音乐版权及作者电脑上的私有后端。接收方需要准备自己的素材和制作环境。
