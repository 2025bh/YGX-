# 家具短视频制作

版本：1.0.0，2026-10-10。把真实家具素材做成可审片、可继续编辑、可迁移的短视频，不承诺播放量或节省时间。

## 开始前

1. 读取[完整规则](references/production-rules.md)。当前任务的明确要求优先于默认样式，但不覆盖真实业务事实与执行权限。
2. 读取当前项目和账号的配置及任务恢复点；没有配置时用[配置模板](assets/project-config.example.json)建立工作副本，仅问缺失且影响执行的输入。不要根据聊天提到的品牌自动切换项目。
3. 检查本机素材、FFmpeg/ffprobe、Python、剪映版本和可用操作工具。这个 Skill 不包含素材、声音模型、剪映订阅或剪辑后端。缺工具先说明；未经授权不安装、付费或上传素材。
4. 定位用户指定工作目录，或者由当前 cwd/Git 根目录确认 PROJECT_ROOT。所有项目路径相对这个根解析；绝不依赖作者的盘符、用户名或本地脚本。

## 工作流程

- 绑定项目、账号、任务、模板版本、执行负责人、素材范围及独立输出目录。同窗口只保留一个执行焦点；切换前记录已完成、剩余、下一步、证据。已有任务修订沿用编号，另存版本。
- 先低成本索引参考和自有素材，再实际看联系表及候选区间。分镜切点检测只是候选；记录未观看区间，不靠文件名或技术分数宣称语义匹配。
- 以可见画面和已确认事实写文案；完整来稿按原稿制作审片版，未证实承诺单列待核实，不擅自改写。给每句标主体、动作、要证明的细节与选片依据。
- 当前默认只选9:16源视频并输出9:16，不裁横版凑数。同一原片整条只用一次；普通镜头1.5至4秒。只有一句连续列举不同产品时可短于1.5秒；同一产品部件不按名词快切。
- 无真人原音、且任务采用当前配音路线时：剪映“文本→朗读→真人播客女”，生成干净旁白，再选音频“换音色→克隆音色→春燕”。这是音频转换，不是春燕重新朗读；不是瑶瑶。先试听小样，不保证情绪完全保留。音色不可用先停下报告，不擅自替换。
- 按最终配音对齐镜头和字幕，加入低音量音乐及少量强调音效。字幕、标题和强调文字逐条独立，关闭字幕/歌词同步；重点词黄色填充、黑描边及阴影，普通字白色。
- 先预审候选片段和切点，再渲染审片MP4，核验时间线及可编辑工程。用[镜头计划模板](assets/shot-plan.example.json)记录结构，运行下面校验。脚本只检查所给计划，不替代真实媒体/语义/原生验收。
- 剪映交付须遵循[移机与原生验收](references/jianying-delivery.md)：源素材打包、重定位、唯一ID、安全登记、打开编辑保存重开及导出。没有兼容导出器时可通过本机剪映UI完成，不假称作者的私有后端已经安装。

```text
python <本Skill目录>/scripts/validate_plan.py <本任务的shot-plan.json>
python <本Skill目录>/scripts/test_validate_plan.py
```

## 交付

给唯一当前版本的MP4、原创/用户文案、镜头清单、可编辑剪映草稿及收齐素材的工程包；需要时附封面和发布文案。明确“文件生成、索引登记、首页可见、原生编辑保存重开、用户认可、正式发布”各自状态。未经确认不自动发布，不删除旧产物。

同事移交或新环境接入时，将[项目方案与规则文档](https://github.com/2025bh/YGX-/blob/main/docs/colleague-handoff.md)交给接收方，或由发送方附上该文件。本Skill的执行规则与资源全部随子目录安装；交接文档是业务介绍，不是运行依赖，不要求访问作者电脑。
