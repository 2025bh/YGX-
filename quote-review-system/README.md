# 忆古轩报价审核台

本地运行的CAD报价逐题纠错系统。先导入AI报价和用户指定的老师傅报价，再把缺项、多项及数据差异整理成部件题卡，配合同版CAD核对，最后逐图查漏。

## 老师傅怎么用

1. 打开审核台，先进入“逐题练习 · 十种常见纠错”熟悉流程。练习数据全部虚构。
2. 真实项目导入AI结果，再导入老师傅的对照表。AI结果需要原图号和部件名称；人工表缺图号时先出配对卡，绝不把序号冒充绿色图号。名称或拆分方式不一致时也先配对。人工表单位mm如指规格尺寸，可勾选一次确认：单有面积列解释为㎡，单有总长列解释为米，两列都有值仍待核。
3. 每题选择“采用老师傅”“采用AI”“两边都不对”或“暂时待查”。可以一句话说明问题，不必重复写三段解释。
4. 核对修改前后和工程量预览，确认后保存并继续。可以查看历史、撤销最近确认、补漏项、粘贴截图并框选或画箭头。
5. 最后逐图核对部件清单。独立CAD图框清单中的零报价项图也要检查。没有完整图框清单时，系统明确限定查漏覆盖范围。

老师傅报价也是对照来源；最终以同版CAD证据及确认规则判断。项目纠错自动留存，通用规则以待适配候选保存。语音使用电脑现有语音输入方式，本版未内置语音识别模型。

## 本地运行

建议Python 3.12及Node.js 22。Windows首次双击“安装运行环境.cmd”，完成后双击“启动报价审核台.cmd”，打开 http://localhost:4188 。已安装依赖时直接启动。

其他系统或手动安装：

```text
python -m venv .venv
# 激活自己的虚拟环境后执行：
python -m pip install -r requirements.txt
npm ci --ignore-scripts
npm run build
python run.py
```

本机入口自动使用本机管理员。其他电脑需要由管理员创建账户；局域网版先运行prepare_lan.py并按输出配置受信任证书，随后使用“启动局域网版.cmd”。不会自动修改防火墙或跳过证书警告。账户权限目前为管理员和老师傅，销售提报权限留后续。

## CAD与文件

在项目中绑定同版DWG。AI JSON可以带bounds（图框四坐标）、frame_index、frame_handle和经验证的对象句柄；不能用截图像素猜CAD坐标。连接助手适配Windows与AutoCAD2021，在审核台“本机CAD”入口下载，解压后双击“启动CAD连接.cmd”。第一版只保证可靠图框定位，对象高亮尚未实现。

原生矢量PDF生成：设置QUOTE_ACCORE指向自己安装的accoreconsole.exe（可以通过注册表自动发现），运行：

```text
python -m backend.native_pdf
python scripts/render_preview_images.py
```

在独立、哈希校验的工作副本上出图；源图不改。PDF预览独立于报价原稿保存。

完整图框清单JSON可从项目“绑定CAD / 图框清单”导入，也可通过scripts/import_frames.py导入。清单必须绑定source_sha，包含frames数组，每个图框有index、figure、bounds、可选handle。complete只在已确认清单覆盖完整同版CAD时设为true。未知图号保留待核。

## 数据与计算

运行数据默认只存在data/，可以用QUOTE_DATA_DIR另设目录。真实原稿、DWG、截图、规则案例、数据库和助手连接配置不得公开上传。本仓库公开副本只带虚构演示项目与通用方法。

按单位计算面积、延米或数量；延米项目不算计价面积，缺单价金额留空。尺寸保留原值、工程量显示两位、金额不使用显示取整值。B端需确认本项目计价口径。最低面积只对明确确认的对象生效。导出18列审核稿，外部文案按纯文本写入，不执行外部公式。

账户设置可下载完整备份。restore_backup.py只恢复到新目录，检查数据库、文件哈希和附件引用，保留当前数据。旧备份无哈希清单时只能做数据库及引用检查。

## 验证及第一版边界

```text
python -m pytest tests -q
node --experimental-strip-types --test tests/suggestions.test.ts
npm run build
```

已实现导入对照、歧义配对、差异题卡、第三种答案、待查、撤销、版本冲突、截图标记、确定算量、逐图查漏、独立图框清单、18列导出和备份恢复。

本版接入既有AI识别结果；未提供自动解析任意新DWG并独立生成完整报价的识别模型。CAD连接、账户部署与使用效率需在老师傅电脑实测；门、门楣、五金和单价制定沿项目已确认范围继续完善。本地测试和公开发布不等同业务上线。
