# 忆古轩项目交付系统 v2.2

手机与电脑可用的项目交付网站，包含定制、板式、成品、清仓、外接五类项目的主要业务流程。本目录是当前隔离试用系统的**公开脱敏副本**，不是重新实现的简化样例。

> 仅限本地隔离演示。飞书真实登录、原生审批、事件回调和正式通知尚未接入。不要直接部署到公网或使用真实客户资料。

## 快速运行

安装 Node.js 22 或以上，进入本目录，无需安装网站运行依赖：

```powershell
$env:YGX_MODE='demo'
$env:YGX_PORT='8299'
$env:YGX_DEMO_NAMESPACE='public-demo'
node server.js
```

打开终端显示的地址，默认 http://127.0.0.1:8299/ 。端口占用会自动尝试后续端口。健康检查地址为 `/healthz`。终端运行期间窗口不要关闭，按 Ctrl+C 停止。

Windows也可运行 `./start-preview.ps1` 隐藏启动。该脚本使用 `preview` 命名空间，首次启动生成新的演示库，不含原电脑项目和附件。

## 功能与流程

- 项目建项、编号和详细地址展示、岗位权限、项目详情、待办直接进入所需节点。
- 设计分配、量尺、图纸、初稿确认、复尺、最终确认、拆单、转接生产和五金单。
- 备料、材料到场、开料、木工、打磨、油漆、包装，外购独立并行与采购待办。
- 分批生产、批次状态、出货申请、财务/发货条件审批分工、实际发货。
- 项目级安装跟踪、安装/客户验收及独立售后工单。
- 节点查看和带原因退回，保留资料及已发生的出货事实；最终报价独立权限。
- 手机简洁页、日期/人员/多选/文件组件、管理员附加字段、草稿保存、部分断网草稿。
- 定制/板式销售催促设计，系统通知与待办直达，飞书通知接口占位。

## 代码入口

`server.js` 服务/API/业务联动，`spec.js` 共用节点与字段，`workflow-control.js` 退回/推进约束，`custom-fields.js` 附加字段，`json-store.js` 本地存储，`feishu.js` 模拟适配与接入契约，`public/` 完整界面。

供接手AI：先读本README、业务流程和交接说明，再读代码。保留现有成果、小步改动，每次回归；不要直接整体重写，也不要把本地模拟审批宣传为真实接入。

## 测试

```powershell
node test-workflow.js
```

该脚本只在工程自身生成独立的虚构测试命名空间。浏览器专项另外需要开发依赖 `npm install` 和本机Edge，随后运行相应 `test-*.cjs`；不得把会写数据的测试指向现有8299、8199或任何生产服务。历史测试结果未公开上传，本次公开版回归结果写在发布说明。

## 安全

首次运行会生成 `demo-data/` 和 `demo-uploads/`；这些目录包含账号/会话/项目与附件，禁止提交Git。仓库公开不等于软件可以安全公网使用，详见 [SECURITY.md](SECURITY.md)。
