# 安全边界

本版本只适合隔离演示，默认演示密码和JSON存储不能用于公网生产服务。禁止把端口直接开放互联网；局域网演示也应限可信测试人员。

公开副本不含原业务数据库、客户附件、真实员工目录、访问令牌、飞书应用凭据或原工作区历史。源码预置身份和客户样例已替换为演示值，但岗位关联逻辑保留。

正式使用前仍需完成强身份认证、密码存储升级、统一权限/文件授权、HTTPS、备份恢复、并发与幂等、真实飞书审批回调及真实员工验收。前端按钮隐藏不能替代服务端授权。

不要公开上传运行时目录、`.env`、日志、密钥、会话、附件、生产截图。管理员配置与真实飞书接入应在隔离环境核验，不通过改本地审批状态冒充正式审批。
