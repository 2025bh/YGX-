**第 3 步：补业务闭环缺口。** 优先统一异常账本、一次出货覆盖多个有效批次、审批轮次、安装齐货派工门禁；每做一个能力都用同一套五类流程回归。未确定的业务决定（图纸版本文字、批次建齐责任等）先让业务负责人定稿。

**第 4 步：隔离接入飞书和正式部署。** 先明确业务主数据唯一权威来源（本系统还是飞书 Base），再接本人飞书登录、原生审批、事件回调和通知；逐岗位、逐字段验证真实权限。最后做 HTTPS、备份、实体手机、故障与恢复、旧系统并行切换方案。**没有这些验收，不拿真实客户项目在 8299 上试运营。**
